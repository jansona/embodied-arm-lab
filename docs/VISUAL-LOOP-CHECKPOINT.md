# 当前主路线：Qwen 直接视觉控制

主入口 `python -m embodied_arm` 默认只预览。执行使用：

```sh
python -m embodied_arm --live --config ../arm-provider.json
```

默认 `--mode qwen_direct`：完整 observer+wrist 两路 640×480 图像 → Qwen 选择一个动作 → 机械边界校验 → 有界执行 → 新图像。完成来自 Qwen 图像判断，不是独立物理真值验证；没有本地语义视觉提取器或固定抓放配方。

`--mode two_model` 显式开启对照：Qwen 判断/意图 → Jev 选动作。默认模式不加载或调用 cerebellum；现有双组 v2 配置仍兼容；直接模式只填写 brain，也允许省略 cerebellum，或保留空密钥。只有对照模式需要两组配置。

动作集合共 33 个：XYZ 六方向 × 0.5、1、2、4、8 mm，加夹爪开/合各 10 个百分点、保持。0.5 mm 是指令粒度，不是视觉精度；执行器保持工具朝下，不选择手腕朝向。场景仍是原有模拟积木；没有固定物体 ID 的决策合同不等于任意场景可靠。

单任务最多 200 次动作决策/420 秒。共享 worker 窗口 600 秒、Qwen 最多 201 次（包括最终观察）；直接模式 Jev 0 次，对照模式最多 200 次。等待计时，不自动续期。`--cycle-max-calls 32` 标记进度复核，不增加调用；`--camera-interval` 仅用于本地预览。Stop 后的新任务仍使用原会话剩余时间和累计预算。

启动器将模式同时传给应用 `SO101_CONTROL_MODE` 和 worker `--mode`；`SO101_VISUAL_LIVE` 只由 `--live` 开启。缺服务或模式不匹配不得回退到其他控制路线。

本轮没有真实 API 调用，真实模型完整抓放尚未验收。新直接模式范围内 322 个测试通过（38.58 秒，1 个既有弃用警告），独立评审已通过。真实 IPC/物理通路使用模拟 Qwen 响应，0.5 mm 指令得到 0.499710 mm 编码器 FK 位移，Jev 调用为零；这不是视觉定位精度或抓放成功证明。本轮未重新运行完整旧/新测试集合。旧 CV 和此前双模型测试结果仅为历史证据，不作为直接模式成功证明。
