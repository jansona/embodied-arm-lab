# 当前主路线：Qwen 逐动作视觉闭环

主入口是 `python -m embodied_arm`，应用为 `embodied_arm.web.app_visual:app`；`--live --config <仓库外配置>` 启动单个 `visual_loop_worker`。默认预览不调用模型，外部 v2 配置保持原格式。

完整 observer+wrist 图像交给 Qwen，Qwen 给出当前视觉判断和动作意图，Jev 在 33 个有限动作中选择，执行一个有界小步，再获取新图像交给 Qwen。完成状态来自 Qwen 的图像判断，不等于独立物理真值验证。接近/抓取概念可以复用，但不强制固定动作配方。

当前主流程不使用旧 CV 物体跟踪、ROI 裁剪或固定抓放阶段脚本。机器人状态可用于执行约束，不向模型补入物体真值。worker 会话最多 Jev 200 次、Qwen 201 次/600 秒，多出的一次 Qwen 用于最终观察。单任务 Jev 上限 200 次/420 秒；实际还受剩余 worker 窗口限制，最终观察也须有可用 Qwen 预算。没有自动续期或空闲调用，不控制硬件。

本轮未调用真实 API，真实 Qwen/Jev 完整抓放尚未验收。新路线范围内的离线验证通过 213 个测试，配置检查另通过 37 个测试；独立评审已通过。未重新运行完整旧/新集合，先前旧路线聚合测试已取消，不作为本次发布证据；旧 CV 路线的物理失败和测试计数不属于此路线的验收结果。

`--cycle-max-calls 32`（1–200）控制进度复核间隔，在既有逐动作 Qwen 请求上标记复核，不增加额外调用。`--camera-interval` 仍用于本地预览采样，不触发周期模型请求。

默认使用完整的 observer+wrist 两路 640×480 图像，不需要本地 CV 高分辨率处理。Jev 一次请求选择方向和距离：XYZ 六个正负方向 × 0.5、1、2、4、8 mm 共 30 个平移动作，加上夹爪开/合各 10 个百分点与保持，共 33 个选项。Python 只校验所选动作及边界；0.5 mm 是指令粒度，不是视觉定位精度。笛卡尔执行器保持工具朝下，不由 Jev 选择手腕朝向。新入口由 `SO101_VISUAL_LIVE` 控制（启动器 `--live` 设置为 1，预览为 0）。

默认模拟场景仍包含原来的积木。新决策合同不绑定固定物体 ID 或物体几何，也不使用旧语义视觉提取器，但这不能证明任意场景可靠；完成仍是 Qwen 的图像判断。独立冒烟验证走真实 IPC 与物理执行器、使用模拟模型响应：请求 0.5 mm，编码器 FK 观察到 0.499710 mm。这验证动作通路，不证明视觉精度、真实 API 或抓放成功；不引用旧 CV 回归作为新路线验收。
