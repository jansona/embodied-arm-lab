# 下一阶段：本机实验验证

## 启动

配置使用仓库外已有的独立大脑/小脑配置，不在网页填写密钥。

```sh
.venv/bin/python -m embodied_arm --live --config ../arm-provider.json
```

输入任务，按 Enter 或“提交并执行任务”。默认预览不执行；此入口只允许 SO101 模拟器，不控制硬件。主动提交可能产生模型费用，没有定时模型调用或自动续期。

## 实际配置和运行语义

- `observer_wrist`：固定观察相机 + 随手腕运动的相机；每帧用机器人 FK 更新相机标定，不读取物体真值代替图像定位。旧相机组合仅用于诊断
- 感知 1920×1440、scaled ROI、`shadow_free_rgb_v1`；网页预览 640×480。高分辨率会增加 CPU 开销，不保证实时速度或消除遮挡
- 对话 10 次/600 秒，最多 8 次复核；视觉 10 次/600 秒；Jev 会话 200 次/420 秒
- 一项任务的连续步骤共享 200 次/420 秒；每个局部周期最多 16 次调用，周期复核与允许的场景修订合计最多 8 次
- 周期结束暂停 → 新图像 → 大脑复核 → 从未完成 primitive 继续；不重新播放已完成抓取、释放或前序步骤
- 会话从 worker 启动计时，任务从提交计时，实际执行受两者剩余时间中较短者限制。等待、复核、续接都不重置预算；界面应以实际剩余会话为准
- 未知障碍、过期图像、置信度不足、停止和预算到期仍中止执行。堆叠成功需要可见的底块支撑关系，底块隐藏时必须报告无法验证

## 本机验收顺序

1. 确认界面的实际相机配置、两路画面、标定和剩余 worker 时间；初始观察失败时先解决失败，不继续动作
2. 提交单块移动，检查每个动作都有新图像和实际执行事件；记录失败原因，模型文字不能代替完成证据
3. 观察周期预算触发的暂停/复核/继续，确认已完成动作不重放、累计调用/时间不重置
4. 测试停止、worker 到期、持续遮挡及隐藏底块，必须停下或明确验证失败
5. 单步成立后再验证连续任务与堆叠，只有最终图像支持任务目标才能报告完成
