# 动态闭环检查点

本次改进把局部目标更新放在每次 Jev 决策之前：获取当前 RGB 证据，重新计算阶段目标和不确定度，检查路径，再请求一个有界动作。执行后重新观察；到达判断也必须使用新观察。超过 3 秒的视觉输入对应的模型回复不会驱动机械臂，而会消耗已用调用预算后重新观察。

- Qwen 负责初始任务和事件驱动的高层修订，不随相机每帧调用
- 接近和下降阶段从最新图像位置重算目标；方向仍由 Jev 选择
- 局部周期默认最多 32 次 Jev 调用，到达周期预算后暂停、重新观察并请求高层复核；持续遮挡仍停止，不沿用旧坐标
- 周期复核和可安全修订的 scene_changed 合计最多 8 次；后者仍需执行器明确报告可安全修订。连续步骤共享 200 次调用/420 秒，已完成 primitive 不重放，从未完成阶段继续；这不构成物理恢复成功证据
- UI 区分观察、模型选择、实际应用的微动作、局部目标达到与整项任务通过图像验证
- 普通预览不开放抓放；`--live` 显式接通实验性模拟器执行。该路径只接受精确的 `SO101Simulation` 类型，不连接物理硬件；悬停开关不代替任务模式
- 执行使用真实 Qwen/Jev worker IPC，缺服务时拒绝，不回退到假模型或脚本。`validated` 仍为 false，界面给出不阻断提交的实验性提示；每步的图像、空间、置信度、预算和取消检查仍可中止任务

## 已验证和未验证

独立离线测试覆盖目标受扰动后的反向纠正、旧观察不能完成任务、模型迟到、停止、共享预算和修订时场景变化。真实 SO101 伺服配合 FakeJev 的合成目标扰动测试通过；这是控制逻辑/物理测试，不是图像识别或真实模型验收。

实际渲染 RGB → 离线语义 fixture → FakeJev → PyBullet 的抓取探针执行了 11 次控制器调用、10 个物理动作，随后因蓝块左相机遮挡停止。目标更新已使用新 RGB，但整项抓取未完成。该历史云端探针不构成真实模型验收，也不能预测用户本机是否成功。此前 640 像素感知路径会在运动前因精度不足被拒绝；当前显式实验执行配置见下文。

三次静止重观察不能解除该遮挡。离线姿态诊断发现蓝块双目在下降到闭合之前持续不可用，闭合后短暂恢复，提升时再次超过既有 4 像素关联门限。单目障碍体积仅完成诊断，没有进入生产执行器；没有缩小未知区域、降低阈值或读取模拟器物体真值来强行通过。

下一步需要独立评审一个能持续看到目标与障碍的观察方案，或者证明保守障碍体积对完整机器人几何的安全性。当前没有完成这项验收。云端模型访问限制仍独立存在，本次没有发起真实模型请求。

## 当前实验性执行配置与操作

- 主操作为“提交并执行任务”或 Enter：自动观察 → Qwen 规划 → Jev 动作 → 反馈验证。Shift+Enter 换行
- 折叠面板的对话/计划预览不提交、不排队；模型文字中的“等待执行”不代表 runtime 已创建执行任务
- `--live` 启动的应用使用 1920×1440 感知、scaled ROI 跟踪、`shadow_free_rgb_v1` 无阴影渲染；实际相机配置为 `observer_wrist`，固定观察相机 + 手腕相机；手腕移动时逐帧用机器人 FK 更新标定。旧组合仅用于诊断。实时网页预览为 640×480，界面公开显示这些配置。高分辨率感知增加 CPU 和处理开销
- 该配置是显式开启的实验路径，不是已验证的可靠控制配置；缺失或不可靠的 RGB 仍会阻止动作，不放宽现有阈值
- 会话 Jev 窗口为 200 次/420 秒，单任务连续步骤共享 200 次/420 秒；Qwen 对话和视觉分别为 10 次/600 秒，brain 最多 8 次复核。会话从启动计时，实际任务时间受剩余会话限制，不自动调用或续期
- `--live --workers-only` 只启动 worker，不能改变已运行预览应用的环境/任务模式；普通用法是单机 `--live` 同时启动应用和 worker

本轮没有真实 Qwen/Jev 成功抓放证据。前述 11 次假控制器调用、10 个物理动作后因蓝块遮挡停止的记录仍按原结果保留；开启实验入口没有把该失败变成成功。

下一阶段的操作、暂停/复核/继续语义和严格可见支撑验收见 [验证计划](NEXT-PHASE-VALIDATION.md)。新增相机路径此前的初始目标过期问题已修复（先记录目标，再初始化耗时 tracker）；最新复测走实际生产 factory、RGB、模拟 Qwen 响应解析、Jev IPC 和物理仿真：视觉 1 次、大脑 1 次、Jev 4 次模拟调用，实际物理动作 3 次；随后在 approach 阶段以 `perception_rejected` 安全停止。重试 1 次，捕获的恢复错误为 `Moving RGB anchors unavailable`；首次跟踪错误当时未保留，不能推断其具体原因。`verified=false`，无已完成步骤或周期复核，也没有完整抓取/堆叠成功。所有 provider 响应均为模拟，未调用真实 API。首次感知错误保留功能在这次复测后加入，不改变上述历史证据。

当前限制：活动 primitive 的 RGB 身份有效期仍为 120 秒。任务/全局窗口为 420 秒，不会延长该身份有效期；Qwen 语义刷新也不会自动续期已有 primitive 的身份。超期仍可能停止任务。请求遥测只把白名单元数据写入现有 runtime `last-run-audit`，公开 IPC 结果格式不变；这不是实时模型验收证据。

局部周期可用 `--cycle-max-calls 32` 配置（1–200）；共享任务/会话上限仍为 200 次/420 秒。已记录的 4 次调用后视觉失败发生在周期上限之前，增加上限不能解释或修复它。任务活动期间锁定输入，须等待停止确认；后续从当前状态继续，不重置场景。

## 当前补丁：局部裁剪与停止后的连续性

- 离线 ROI 重放中，蓝块右图的 `roi_clipped` 可通过一次有界 2× 裁剪扩展恢复；使用同一份新鲜像素，保留原有身份关联、形状和协方差检查
- 重放位置 x=0.192、0.186 m 通过；x=0.180 m 的 RGB 拟合通过，但仍触发 `excessive_3d_uncertainty`，3 mm 阈值未放宽；更远的 x=0.176 m 为 `ambiguous_face_patches`。这是局部重放结果，没有完整抓取成功证据
- 现保留首次/重试的详细拟合诊断，显示累计调用/动作数、周期进度及 runtime 提示；默认周期 32 次且可配置，全局预算不变
- 活动输入等到 Stop 确认才解锁；随后从当前姿态重新取得新鲜观察，不重置场景。停止时的持物连续性必须由新鲜 RGB 与编码器证据共同支持；仅有 helper 测试，尚无物理持物恢复证明

本补丁没有真实 API 调用；最终完整离线回归通过 1,266 个测试和 121 个子测试，16 个跳过，1 个既有弃用警告，用时 389.69 秒；独立评审已通过，不能把局部裁剪恢复写成整项任务成功。
